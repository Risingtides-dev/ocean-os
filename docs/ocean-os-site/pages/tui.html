One native workbench, backed by the Ocean daemon.

ocean-tui renders chat, native session resume, files, editor, 3D project graph, terminal dock, tool activity, permissions, and daemon health. It does not embed a second TUI or own the agent runtime.

Architecture

Single client surface

Workbench

The async component tree under src/shell/ is the only TUI implementation. The former Track-0 room cockpit, legacy flag, and mesh parity command were removed.

Daemon authority

Turns, tools, providers, permissions, and durable sessions remain in ocean-daemon and ocean-agent. The TUI communicates through HTTP and session-scoped SSE.

Native sessions

The session rail rehydrates UUID-backed transcripts and swaps the scoped event stream in place. --session <id-or-prefix> targets the same native path.

Project surfaces

Bottom navigation exposes sessions, chat, editor, graph, terminal, and files. The graph uses the 3D spatial camera pipeline in shell/spatial.rs.
