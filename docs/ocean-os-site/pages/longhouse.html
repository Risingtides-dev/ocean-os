Ocean OS / Longhouse coordination
slice 3 · source-grounded
non-hierarchical coordination

Longhouse turns agent swarms into observable rooms, marks, and quorum.

Longhouse is Ocean’s coordination layer for multi-agent work: no standing chair, no hidden orchestrator bottleneck, no LLM-trusted governance. Events ride the existing agent SSE bus and the living deck renders the system as an underwater building.

Thesis

Emergent coordination for exploration, escrowed authority for termination.

Source: docs/LONGHOUSE_ORCHESTRATION.md. The chair-led council is discarded; Longhouse keeps the event bus and turn-injection substrate.

01

No standing chair

Agents do not route through a single lead model that decides who speaks and when. Convening is domain-routed and quorum-driven.

02

Daemon-enforced guardrails

Deadlines, quorum arithmetic, credentials, permissions, and termination are computed/enforced by the daemon, not trusted to an LLM.

03

Escrowed termination

A firekeeper role signs the single binding Converged event only when daemon quorum state already says it is valid.

Wire vocabulary

The minimum event family for a visible deliberation.

#[serde(tag = "lh_type", rename_all = "snake_case")]
pub enum LonghouseEvent {
  TopicConvened { topic_id, board_id, federation, trigger, title, deadline_ms },
  Convened { topic_id, members },
  MarkPosted { topic_id, mark },
  QuorumUpdated { topic_id, tallies, leader, distance_to_quorum },
  RoleGranted { topic_id, agent_id, role },
  RoleRevoked { topic_id, agent_id, reason },
  Warned { topic_id, agent_id, strike, reason },
  Converged { topic_id, decision, by },
  Aborted { topic_id, reason },
  TopicClosed { topic_id },
  RunHealth { federation, runs_total, runs_healthy, note },
}
impl LonghouseEvent {
  pub const EXTENSION: &'static str = "longhouse";

  pub fn into_turn_event(self) -> AgentTurnEvent {
    AgentTurnEvent::Extension {
      extension: Self::EXTENSION.to_string(),
      payload: serde_json::to_value(self).unwrap_or(Value::Null),
    }
  }
}
Coordination primitives

The mechanics are concrete, not metaphor.

Longhouse takes the useful substrate from the older council idea and removes the chair bottleneck.

A

Stigmergy

Agents coordinate through a shared blackboard of typed marks: proposal, endorse, inhibit, evidence, and note.

B

Subsidiarity

Most turns do not convene. Escalation is gated by shared-state, irreversible, or cross-boundary predicates.

C

Quorum + inhibition

The daemon computes net proposal weight and distance to quorum; inhibition prevents symmetric deadlock from burning forever.

Deck workspace

The living deck is intentionally separate from Ocean Surface.

../ocean-longhouse-deck uses Leptos 0.8 + Bevy 0.18; Surface is still Leptos 0.7.

Why separate

leptos-bevy-canvas requires Leptos 0.8 and Bevy 0.18. Keeping the deck separate avoids two Leptos majors in one lockfile.

How it integrates

It talks to the daemon over HTTP/SSE like any Ocean client. It can slot into Surface later via iframe/web-component boundary or after Surface upgrades.

Current render model

Four department rooms — Dev, Sales, Content, Campaign — laid out as a 2x2 underwater building. Commons parks bottom-center.

Current demo route

POST /v1/longhouse/demo emits a scripted-but-real sequence of Longhouse events onto /v1/agent/events.
