browser PWA + voice integration

Ocean Surface is the thin client face over the daemon brain.

The sibling repo ../ocean-surface ships a Rust + Leptos browser PWA and a proxy for same-origin daemon access and optional voice services, with native shells developed separately. It holds no agent logic, coding-model provider credentials, or session storage; those stay in ocean-os.

Repo boundary

The face and the brain are deliberately split.

ocean-surface is client-only

The canonical product UI is one Leptos/WASM bundle used by the browser PWA, Tauri native shell, and Chrome extension. It calls ../ocean-os and keeps agent logic, session authority, provider credentials, permission policy, and tool execution in the daemon.

Source: ../ocean-surface/AGENTS.md:3-19, ../ocean-surface/README.md:1-37

Workspace crates

crates/ocean-surface-ui is the canonical Leptos CSR/WASM UI. crates/ocean-surface-proxy serves that bundle and forwards browser requests to the daemon. crates/ocean-tauri is the native desktop shell over the same bundle; crates/ocean-gui is retained legacy GPUI source, not the current native product.

Source: ../ocean-surface/AGENTS.md:3-8, ../ocean-surface/README.md:89-99

Connection model

The UI subscribes to daemon events and reacts with Leptos signals.

All assistant text, thinking, tools, components, browser activity, and turn status arrive over SSE.

01

Bootstrap

On load, App creates a Daemon handle and calls bootstrap_then_connect(). The proxy's /api/config resolves daemon URL, voice readiness, maps key, LiveKit room hints, and tldraw sync hints.

Subscribe

Same-origin proxy

The proxy makes phone/PWA usage practical.

Two jobs

The proxy serves the compiled WASM bundle and relays browser STT/TTS requests to daemon-owned voice endpoints, so provider credentials never enter browser or proxy state. Its default bind remains 0.0.0.0:8790; tailnet/LAN use requires Surface auth, while trusted local development should bind loopback explicitly.

Source: ../ocean-surface/crates/ocean-surface-proxy/src/main.rs:1-14, ../ocean-surface/crates/ocean-surface-proxy/src/main.rs:233-302, ../ocean-surface/crates/ocean-surface-proxy/src/main.rs:1792-1913

Reverse proxy routes

The proxy forwards daemon API routes through the same origin: turns, events, sessions, models, projects, LiveKit token, and request cancellation. This avoids hardcoded localhost and mixed-content failures on a phone or tunnel.

Source: ../ocean-surface/crates/ocean-surface-proxy/src/main.rs:349-470

Daemon voice seam

Surface can handle audio around the daemon, but POST /v1/agent/voice itself accepts an already-transcribed transcript. It tags the request client_type: "leo-voice" and delegates to the normal agent-turn path. The endpoint does not capture a microphone, run STT, listen for a wake word, synthesize speech, or by itself provide a completed voice UX.

Source: crates/ocean-daemon/src/main.rs:643, crates/ocean-daemon/src/main.rs:5379-5504

Not the session store

Sessions remain daemon authority. Surface explicitly creates or selects a session, installs the returned id before opening scoped SSE, and reuses that id on turns; passive turn responses or SSE never steal focus.

Source: ../ocean-surface/crates/ocean-surface-ui/src/daemon.rs:3483-3559, ../ocean-surface/crates/ocean-surface-ui/src/daemon.rs:3739-3745

Component surface

Agent-emitted components render as real Leptos UI.

This is the path scheduled heartbeat routines should eventually use for visible PWA status cards.

Render dispatch

ComponentView maps component_render kinds to live views: kanban, form, table, progress, markdown, dashboard, chart, interactive plot, timeline, stat, file tree, diff, code, callout, gallery, confirm, deck, map, and video.

Source: ../ocean-surface/crates/ocean-surface-ui/src/components.rs:198-278

Interactions go back to daemon

Forms, cards, file trees, confirmations, maps, and other interactive components send POST /v1/component/event so a pending component_wait tool can resume.

Build note

The shared UI is a Trunk-built WASM bundle. run-surface.sh builds it and the release proxy; run-tauri.sh builds the same bundle before launching the native shell. Tailnet/LAN serving requires OCEAN_SURFACE_USER and OCEAN_SURFACE_PASS.
