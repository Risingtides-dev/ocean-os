Current extension

The MV3 side panel ships the Surface app inside Chrome.

Grounded in ../ocean-surface/extension/manifest.json, background.js, and sidepanel.html.

MV3

Manifest V3

The extension is named Ocean, version 0.1.0, with permissions sidePanel and storage.

UI

Side panel shell

sidepanel.html loads the compiled Surface assets from extension/dist and boots ocean-surface-ui.wasm.

API

Local daemon access

Host/CSP permissions allow connecting to http://127.0.0.1:4780 and ws://127.0.0.1:4780.

Open behavior

One click opens Ocean next to any tab.

// ../ocean-surface/extension/background.js
chrome.action.onClicked.addListener(async (tab) => {
  await chrome.sidePanel.open({ tabId: tab.id });
});

chrome.runtime.onInstalled.addListener(() => {
  chrome.sidePanel.setPanelBehavior({
    openPanelOnActionClick: true
  });
});

Rust browser layer

ocean-browser gives Ocean controlled page perception and action.

Grounded in crates/ocean-browser/src/lib.rs and perception.rs.

Navigate + read

navigate, read_page, and screenshot make browser state observable before the agent claims anything.

Act

click_selector, click_xy, type_text, press_key, and scroll_by execute browser actions.

Inspect

eval_js, read_console, and read_network support debugging and live page analysis.

Launch control

LaunchConfig supports profile directory, profile name, extension dir, executable, headless mode, and DevTools port.

Perception schema

PageRead returns URL, title, visible interactive elements, text, and a visual_hint flag.

Element refs

ElementRef gives selector-like refs, role, and text so tools can click precisely instead of guessing screen coordinates.
