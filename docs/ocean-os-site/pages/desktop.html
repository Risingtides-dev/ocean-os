Ocean OS / Clients / Native desktop app
Tauri · shared Surface UI
native Tauri shell

Desktop is the same Ocean Surface in a native host.

The sibling ocean-surface repository owns one Leptos/WASM interface for browser/PWA and desktop use. ocean-tauri supplies native window, filesystem-dialog, and path-watching capabilities around that shared UI. Agent authority remains in ocean-daemon.

Ownership

One interface, two host environments.

shared UI ocean-surface-ui

Owns the transcript, composer, sessions, projects, models, component renderer, canvas ledger, voice controls, and daemon event handling used by browser and desktop.

Source: ../ocean-surface/crates/ocean-surface-ui/src/app.rs, ../ocean-surface/crates/ocean-surface-ui/src/daemon.rs

native host ocean-tauri

Owns native process setup and commands that cannot be provided by a browser: directory selection and watched-path events.

Source: ../ocean-surface/crates/ocean-tauri/src/lib.rs, ../ocean-surface/crates/ocean-tauri/src/host.rs

Runtime path

The shell does not become a second agent runtime.

01

Launch

The Tauri process opens the desktop window and loads the shared Surface bundle.

02

Attach

The UI chooses or creates a daemon-owned session and submits client_type: surface-tauri.

03

Stream

Session-scoped SSE carries text, thinking, tools, components, canvas patches, browser activity, and completion.

04

Render

Leptos signals update the same component and canvas implementations used by the web/PWA host.

Native bridge

Only host-specific capability crosses the Tauri boundary.

Directory selection

The UI invokes the native picker when the operator needs to bind a project or workspace to a local folder.

Path watching

The host watches requested local paths and emits structured change notifications back to the shared interface.

Daemon API

Turns, sessions, projects, models, permissions, and component interactions continue through the daemon's HTTP/SSE contract.

Single client implementation

Desktop behavior belongs in the shared Surface crate unless it requires an operating-system capability unavailable to the browser host.
