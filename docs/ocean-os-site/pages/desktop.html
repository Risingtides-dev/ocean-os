Ocean OS / Clients / Native desktop app
sibling repo · ocean-surface
native GPUI cockpit

The desktop app is a native steering shell, not a bundled daemon.

The native app lives in the sibling repo at ../ocean-surface/crates/ocean-gui. Its job is rich local UX: GPUI windows, editor/workspace panes, model/session/project controls, component surfaces, and canvas/web hosting. Agent authority, sessions, tools, permissions, and provider calls still live in ocean-daemon.

Daemon contract

The native client speaks the same HTTP+SSE API as the web and TUI.

Daemon route
Purpose

Show online/degraded/offline daemon state and backend label.
submit_turn

Streaming model

The GPUI shell protects itself from cross-session event bleed.

Session-scoped SSE URL

agent_events_url adds ?session_id=<id> when a session is known, so the daemon can ship only that session's events to this desktop connection.

Source: ../ocean-surface/crates/ocean-gui/src/shell/daemon.rs:500-509

Generation guard

Every reconnect increments an agent_event_generation. Older listener threads stop forwarding as soon as a newer session stream supersedes them.

Source: ../ocean-surface/crates/ocean-gui/src/shell/view.rs:3080-3118

Typed event blocks

The native agent model supports text, thinking, tool calls, and full component blocks. It also tracks token stats for input/output/cache/tokens-per-second.

Source: ../ocean-surface/crates/ocean-gui/src/shell/agent.rs:17-72

Adoption filter

apply_agent_event ignores events from other sessions unless it is adopting a just-created/started stream for the active submit, then applies GUI commands and transcript updates.

Source: ../ocean-surface/crates/ocean-gui/src/shell/view.rs:3173-3210
