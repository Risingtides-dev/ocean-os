model routing + credential readiness

Ocean separates model selection from provider transport.

ocean-providers resolves the operator's chosen model, provider, base URL, context window, output limit, credential source, and readiness. ocean-protocol then streams a provider-agnostic event model across Anthropic, OpenAI-compatible chat completions, Codex Responses, and Google Gemini adapters.

Model resolution

The daemon never silently picks a hardcoded model.

01

Read selection

resolve_model_selection reads OCEAN_MODEL, then OCEAN_DEFAULT_MODEL. If neither exists, it returns NoModelSelected instead of silently choosing for the operator.

Source: crates/ocean-providers/src/lib.rs:315-329

02

Normalize aliases

Model names are trimmed, lowercased, and spaces/underscores become dashes. Aliases such as DeepSeek V4 Pro, v4-pro, gpt-5-5, and sonnet route to canonical ids.

Source: crates/ocean-providers/src/lib.rs:330-474

03

Resolve credential

Credentials resolve from provider-specific env vars first, then the Ocean auth file. Codex uses an OAuth access token from the openai-codex block.

Daemon model API

Clients hot-swap models without restarting the daemon.

Read and list

GET /v1/model returns the current provider/model. GET /v1/models returns the current model plus ocean_agent::known_models() for dropdowns.

Source: crates/ocean-daemon/src/main.rs:644-655, crates/ocean-agent/src/lib.rs:20-22

Set

AgentRuntime::set_model resolves a fresh provider config with OCEAN_MODEL overridden, validates credentials, atomically replaces runtime state, and persists the chosen model as last-used.

Source: crates/ocean-agent/src/lib.rs:161-188

Startup precedence

On startup, explicit OCEAN_MODEL wins; otherwise the persisted last model is injected; otherwise provider resolution can report no selection. This is why restarts resume the operator's last model.

Source: crates/ocean-agent/src/lib.rs:730-751

Backend name

The runtime backend label is provider/model, so within-provider swaps are visible instead of just showing the provider name.

Credential paths

Environment variables win over auth files.

# model choice
OCEAN_MODEL=deepseek-v4-pro
OCEAN_DEFAULT_MODEL=deepseek-chat
OCEAN_PROVIDER=openai-compatible
OCEAN_OPENAI_BASE_URL=https://example.com/v1

# credential examples
OCEAN_DEEPSEEK_API_KEY=...
OCEAN_OPENAI_API_KEY=...
OCEAN_ANTHROPIC_API_KEY=...
OCEAN_MINIMAX_API_KEY=...
OCEAN_MOONSHOT_API_KEY=...
OCEAN_AUTH_FILE=~/.config/ocean-rs/auth.json

Default auth file

If OCEAN_AUTH_FILE is not set, Ocean looks under OCEAN_CONFIG_DIR/auth.json, then $XDG_CONFIG_HOME/ocean-rs/auth.json, then ~/.config/ocean-rs/auth.json.
