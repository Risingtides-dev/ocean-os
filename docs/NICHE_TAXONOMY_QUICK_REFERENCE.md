### Decision Tree 2: Identify Crossover Potential

```
START: "Can this creator successfully operate in 2+ niches?"

STEP 1: Calculate content distribution
├─ Niche A content: X%
├─ Niche B content: Y%
└─ Other: Z%

IF (X < 40% OR Y < 30%) → NOT a crossover candidate; single niche only

IF (X >= 40% AND Y >= 30%) → Continue to Step 2

STEP 2: Check performance penalty
├─ Engagement rate (niche A only): ER_A
├─ Engagement rate (niche B only): ER_B
├─ Engagement rate (A+B dual content): ER_AB
├─ Observed penalty = (ER_A - ER_AB) / ER_A * 100

IF (penalty > 15%) → Continue to Step 3 (high-risk)
IF (penalty <= 5%) → Proceed to Step 4 (low-risk)
IF (5% < penalty <= 15%) → Proceed to Step 4 (moderate-risk)

STEP 3: High-risk assessment (penalty > 15%)
├─ Check crossover pair in known matrix
├─ If (A, B) in HIGH_SUCCESS_PAIRS → Likely algorithm confusion; coach to improve
├─ If (A, B) in RISKY_PAIRS → Expected penalty; mitigate with content separation
├─ If (A, B) in AVOID_PAIRS → Recommend revert to single niche
└─ Continue to Step 4

STEP 4: Audience overlap
├─ Does creator's audience follow both niches?
├─ Survey: "What other creators do you follow?" → Count both A + B
├─ Overlap % = (both A and B) / total

IF (overlap < 50%) → Risky; recommend niche focus
IF (overlap >= 50%) → Proceed to Step 5

STEP 5: Recommendation
├─ Algorithm penalty <= 5% + Overlap >= 50% → ENCOURAGE ("synergistic")
├─ Algorithm penalty 5-15% + Overlap >= 50% → ENCOURAGE_WITH_STRUCTURE ("pair them thematically")
├─ Algorithm penalty > 15% + Overlap >= 50% → MITIGATE ("separate content days")
└─ Algorithm penalty > 20% OR Overlap < 50% → AVOID or RESTRICT

END: Crossover recommendation assigned
```

### Decision Tree 3: Match Creators to Campaigns

```
START: "Which creators are best fit for this campaign?"

STEP 1: Identify campaign target niche
├─ Target niche: [finance, dance, music, etc]
├─ Sound/trend dependent? (Yes/No)
├─ Primary audience demographic: [age range, gender, interests]
└─ CPM importance: [High, Medium, Low]

STEP 2: Primary niche filter
├─ creators WHERE (primary_niche = target OR secondary_niche = target)
└─ If < 5 creators, widen to ADJACENT niches (use niche adjacency map)

STEP 3: Calculate Niche Fit Score
├─ For each candidate creator:
├─ Primary match score: (0-100) based on niche alignment
├─ Engagement strength: creator ER vs niche benchmark
├─ Audience quality: demographic match + authenticity + purchase intent
├─ Trend alignment: adoption lag (if trend-dependent campaign)
└─ CPM efficiency: creator CPM vs niche benchmark
│
├─ FORMULA: Fit = (Prim×0.50) + (Eng×0.20) + (Aud×0.15) + (Trend×0.10) + (CPM×0.05)

STEP 4: Score interpretation
├─ Score >= 85 → TIER 1 (Excellent fit; prioritize booking)
├─ Score 70-84 → TIER 2 (Good fit; secondary choice)
├─ Score 50-69 → TIER 3 (Acceptable; use if Tier 1/2 unavailable)
└─ Score < 50 → AVOID (Poor fit; only use if no alternatives)

STEP 5: Final validation
├─ Check booking velocity: Is creator available? (High demand = fast booking)
├─ Check momentum score: Is creator trending up? (Growth phase = higher visibility)
├─ Check sound adoption lag: If trend-dependent, prefer < 7 days average adoption
└─ Review notes: Any qualitative concerns? (Brand safety, contract issues, etc)

END: Creator tier assigned; ready for outreach
```

## Momentum Score Quick Assessment

**Without calculations, rough estimate:**

```
Is the creator...?

Rising indicators (1 point each):
☐ Posting 4+ times/week (vs avg 2-3/week for their niche)
☐ Engagement rate up 5%+ in last 90 days
☐ Follower count up 15%+ in last 90 days
☐ Booking 4+ campaigns per quarter
☐ Adopting trends within 7 days (if applicable)

Declining indicators (-1 point each):
☐ Posting <1 time/week
☐ Engagement dropping week-over-week
☐ No campaigns booked in last 90 days
☐ Sound adoption lag > 30 days (if applicable)
☐ Follower count negative growth

SCORE: Sum of + and -

4-5: High momentum ✅ (prioritize for campaigns)
2-3: Moderate momentum ➜ (safe choice)
0-1: Low/flat momentum ⚠️ (check other metrics)
-2 to -5: Declining momentum ❌ (avoid or revive)
```

## Appendix: Common Questions

**Q: A creator is in 3 niches. How do I classify them?**
A: Pick the niche with >40% of content as primary. If no niche exceeds 40%, it's a scattered portfolio—coach toward focus. Rarely do 3-niche creators work; algorithm confusion is severe.

**Q: What if a creator's engagement is 2% but niche average is 3%? Are they bad?**
A: Not necessarily. Factors: follower count (macro creators have lower ER naturally), recent algorithm changes, platform algorithm variance. Check if trend is recent decline (bad) vs consistent (acceptable). If consistent 2%, they're underperforming for their niche—investigate why.

**Q: Can I book a TIER 3 creator if I have budget?**
A: Rarely recommended. TIER 3 creators are lower-performing by definition. Better strategy: Book 1 TIER 1 + 2 TIER 2 creators instead of 5 TIER 3. ROI is better.

**Q: When should I encourage a crossover?**
A: Only if observed algorithm penalty < 5% OR crossover pair is in HIGH_SUCCESS matrix. Otherwise, recommend niche focus.

**Q: How often should I recalculate Niche Fit Scores?**
A: After every creator engagement/CPM update (weekly) OR before each campaign matching (run fresh). Don't use stale scores >2 weeks old.
