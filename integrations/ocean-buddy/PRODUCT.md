# Product

## Register

product

## Users

Ocean operators using iPhone or Apple Watch when they are away from the main workstation. They need to start a short, private foreground conversation, glance at a bounded result, or leave one handoff without navigating an agent dashboard.

## Product Purpose

Ocean Buddy is the smallest trustworthy doorway into Ocean: one tap to speak, immediate state feedback, and explicit bounded capabilities. Success means the interface disappears into the conversation while Ocean remains the session, credential, and tool authority.

## Brand Personality

Calm, capable, alive. Ocean depth and bioluminescent state should feel distinctive without turning a utility into spectacle.

## Anti-references

- Generic settings forms presented as the main product
- Pale blue SaaS card stacks and over-rounded panels
- Smart-speaker clones with an unexplained glowing orb
- Dense agent dashboards, terminal chrome, or provider configuration on the primary screen
- Decorative glass, gradients on controls, and motion unrelated to listening state

## Design Principles

- Voice first: the primary screen answers only whether Ocean is ready, listening, or unavailable.
- Authority stays visible: make privacy, foreground scope, and connection state legible without exposing provider machinery.
- Depth communicates state: use the Ocean ramp for identity and live moments; keep ordinary chrome restrained.
- Progressive disclosure: connection and session configuration live one step away, never above the main action.
- Pair, don't type: the desktop shows a QR code, the phone scans it, the Watch inherits it. Manual entry is a fallback, not the flow.
- Approvals are physical: capability requests appear as cards the operator can swipe or tap, never as silent grants.
- Native trust: preserve Apple interaction, accessibility, typography, and lifecycle conventions.

## Accessibility & Inclusion

Support Dynamic Type, VoiceOver labels, sufficient contrast, reduced-motion behavior, minimum touch targets, and status communication that never relies on color alone.
